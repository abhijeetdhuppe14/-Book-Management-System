Book Management System in C

Project Description

A console-based application developed using C programming to manage book records.

Features

- Add and remove books
- Search books by ID and name
- Display books by author and category
- Update book details
- Sort books by price and rating
- Display the top 3 books by price and rating

Technologies Used

- C Programming
- Structures and Pointers
- Dynamic Memory Allocation using malloc and realloc
- Arrays and String Handling
